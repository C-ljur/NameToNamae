Namaé replaces RimWorld's built-in English pawn and animal names when they are generated.

The included name pack provides Japanese kana readings for 27,914 pawn names and 1,962 animal names. Other languages can be supplied by separate name-pack mods.

[h1]Pawn names[/h1]
First names, last names, and nicknames are replaced when a pawn is generated. Names already stored in a save are left alone.

The mod settings include an optional one-way conversion for existing pawn names. Back up the save before using it.

[h1]Animal names[/h1]
Colony animals can receive proper names when they are born, hatched, tamed, self-tamed, or join the colony. Player-entered names and existing proper names are not changed.

Automatic naming and duplicate avoidance can be disabled separately.

[h1]Other features[/h1]
• Japanese labels and tooltips for developer-mode actions
• Reports for new or untranslated names
• Experimental natural line breaks for Japanese, Chinese, and Korean; disabled by default

[h1]Requirements[/h1]
[url=https://steamcommunity.com/workshop/filedetails/?id=2009463077]Harmony[/url]

RimWorld 1.6

[h1]Compatibility[/h1]
Namaé changes names when they are generated. It does not rename existing pawns automatically.

Name-pack mods should depend on Namaé and load after it.
